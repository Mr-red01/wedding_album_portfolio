# AARAV & ANJALI — Wedding Photography Gallery
### by VELOCITI AGENCY

A cinematic, premium wedding photography gallery built with **React 19 + TypeScript + Vite 8**. Inspired by the wfolio.pro storyboard disk design.

---

## ✨ Features

- **Cinematic Hero** — Full-viewport wedding photograph with couple names, date and scroll indicator
- **Masonry Gallery** — Storyboard-style responsive masonry grid (3 → 2 → 1 columns)
- **6 Album Categories** — Best Photos, Wedding Cam2, Wedding Cam1, Pre Wedding, Sangeeth & Celebration, All Captures
- **Fullscreen Lightbox** — Navigate photos with keyboard arrows or swipe, zoom, download, share, favorite
- **Favorites Drawer** — Persistent favorites saved to localStorage
- **Share & Review Modals** — Client-facing share and review flows
- **WebP + Lazy Loading** — Optimized images with skeleton shimmer placeholders
- **Fully Responsive** — Desktop, tablet, and mobile layouts
- **Vercel Ready** — SPA routing configured via `vercel.json`


## 🚀 Local Development

```bash
npm install
npm run dev       # Starts dev server (also runs syncPhotos.js automatically)
```

Open http://localhost:5173

### Adding Client Photos

1. Drop new `.jpg`/`.jpeg`/`.png` files into `wed_photos/one_sec/`
2. Run `npm run sync` or restart `npm run dev`
3. Photos auto-copy to `public/images/one_sec/` and appear in the gallery

## ☁️ Vercel Deployment (Free Tier)

### Step 1: Push to GitHub

```bash
# In the project folder (d:\wedding_anti)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git branch -M main
git push -u origin main
```

> ⚠️ `wed_photos/` is gitignored — your original full-resolution photos stay on your computer only.

### Step 2: Connect to Vercel

1. Go to [vercel.com](https://vercel.com) → **Add New Project**
2. Import your GitHub repository
3. Framework: **Vite** (auto-detected)
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Click **Deploy**

### Step 3: Every Update

```bash
git add -A
git commit -m "Update gallery"
git push
```

Vercel auto-redeploys on every push to `main`.

## 🎨 Customization

### Change Couple Names / Dates
Edit `src/data/photos.ts`:
```ts
export const GALLERY_META = {
  clientNames: 'AARAV & ANJALI',      // ← Change here
  weddingDate: '2026-06-22',
  photographerName: 'VELOCITI AGENCY',
  expiresOn: 'December 7, 2027',
};
```

### Add Photo Metadata
Edit the `USER_PHOTO_METADATA` object in `scripts/syncPhotos.js` to add titles, categories, and alt text for your photos.
